# Changelog

Format: dated entries, newest first. One entry per working session that
changed the product, the design, or these documents. Product changes also get
a session log in `sessions/`.

## 2026-10-16 — All docs rewritten in plain language

- The owner set a strict writing rule: blunt, plain, face-to-face
  developer voice. Short sentences. Plain words. Basic link words
  only. No decoration, no marketing tone, no AI tone.
- README and docs 01 to 11 rewritten in that voice. Facts, values,
  and rules did not change. Text got shorter in most docs.
- The rule is now in `CONTRIBUTING.md`, in `docs/05`, and in `docs/07`.

## 2026-10-16 — Interview finding, anti-foraging design, and the Garden

- Persona in docs/09 is now interview-grounded: overload slowed creation;
  users over-collect and over-explore instead of working saved material
  (information-foraging diagnosis recorded in docs/01 and docs/11).
- Anti-foraging rules adopted (ADR-003): no Explore feed ever, Saved-First
  intake, collecting earns no progress anywhere, WIP limit reframed as an
  anti-foraging rule.
- The Garden added (docs/11, values in docs/05): one hand-drawn plant per
  day **earned by a completed action** (not by login), monthly 5 × 6 grid,
  a small animal on a 31st day / weekly, colour from the day's Work,
  ~360 plants in the 12-garden year view, tap a plant → its stream entry.
  Nothing wilts, expires, or is counted numerically on the garden screen.
- Day-close flow in docs/10 now ends at the Garden; Garden basic form and
  Saved-First added to MVP scope in docs/06.

## 2026-10-16 — User journey map and guided actions added

- Journey map built per the project's mapping method (docs/09): primary
  persona defined as a hypothesis to validate (cross-format
  creator-learner), macro-task scenario, Future State boundary, 5 phases ×
  6 rows, emotional curve, backstage targets.
- Two Moments of Truth identified: the 60 seconds after first upload, and
  the first Eye render.
- Guided-action rules documented (docs/10): exactly one primary button per
  state, a full state → button map, a 3-decision daily budget, the
  Revise/Derive fork as the only two-button screen, banned anti-patterns
  (blank canvas, guilt mechanics, bare spinners).
- Six experience opportunities (O1–O6) given owners and measurable metrics.

## 2026-10-16 — Project documented

- Concept formalised: Hindsight, one stream, three modes (Hand / Brain / Eye).
- Principal workflow defined as a closed loop on one object (a Work):
  Hold → Direct → See → Return.
- Brain manipulations split into two types: **Revise** (new version of a
  file) and **Derive** (something new made from a file).
- Eye defined as a check as well as a view: it flags thin, orphan, and
  contradictory branches, which become the next Brain question.
- Three founding use cases documented: YouTube/podcast self-enhancement,
  CFA exam study, artwork creation.
- Design system values written down (docs/05), including motion values and
  banned-language list.
- Repository scaffold created: docs, templates, decision records, session
  log process, proprietary licence.
