# 08 — Privacy and IP

## Owner's instruction (2026-10-16)

The Hindsight idea is documented for the owner only. **It is not to be
leaked to, shared with, or suggested to other users.** This repository is the
controlled record of it.

## Repository handling

- The GitHub repository must be created as **private**, and remain private
  until the owner decides otherwise in writing (a decision record).
- Do not paste concept documents, the workflow, or use cases into public
  issues, public gists, social posts, or other projects' repositories.
- Collaborators get access per-person, are named in the session log of the
  session where access is granted, and lose access when their work ends.
- User uploads and private working material never enter this repo
  (see `.gitignore`: `private/`, `uploads/`).

## Product privacy principles (build requirements)

1. **Private by default.** A user's Works, files, notes, and maps are
   visible to that user only. Sharing is a later, explicit, per-item act —
   and it is out of MVP scope.
2. **The user's words stay the user's.** The Daily Direction and notes are
   the person's judgement. Any system draft (e.g. the Eye's drafted
   Question) is labelled a draft and never written into the timeline as if
   the user wrote it.
3. **Provenance is visible.** Every derivative shows what it was made from.
   Nothing appears in a stream without a source the user can open.
4. **Deletion is real.** A user can delete a Work and all of its versions,
   notes, derivatives, and visualisations. The timeline rule "never
   silently overwritten" protects the user from the product, not the
   product from the user.
5. **No training on user material** is implied or permitted by these docs;
   any future processing choice must be opt-in and recorded in
   `decisions/`.
