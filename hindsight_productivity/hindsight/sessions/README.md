# Session Logs

One file per working session, named `YYYY-MM-DD-short-title.md`, made from
`../templates/session-log-template.md`.

Rules (see `../docs/07-development-process-and-prompting.md`):

- The goal is written **before** the session starts.
- The log is finished the **same day**, never batched later.
- Rejected attempts are recorded with their reason — the session-capture
  study this process is based on showed that what designers discarded, and
  which prompts caused regressions, is where the useful record is.
